- 本项目官方 `Docker` 版本（Docker Hub 镜像 `mobufan/fan-imagehost`，默认端口 `8083`）
  - docker-compose 部署（推荐）：
```shell
mkdir -p /root/fan-imagehost && cd /root/fan-imagehost
wget https://raw.githubusercontent.com/meimolihan/fan-imagehost/main/docker-compose.yml
docker compose up -d
```
  - 或直接 `docker run`：
```shell
docker run -d --name fan-imagehost -p 8083:80 --restart=always \
  -v /root/fan-imagehost:/var/lib/fan-imagehost mobufan/fan-imagehost:latest
```
  - 一键脚本安装（systemd，非 Docker）：`bash scripts/install.sh -p 8083 -d /var/lib/fan-imagehost/data -y`
