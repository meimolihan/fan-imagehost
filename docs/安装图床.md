> 推荐环境：Nginx + PHP≥7.0 + Linux

#### Docker 部署（推荐）

```shell
# docker-compose 一键部署，默认端口 8083
mkdir -p /root/fan-imagehost && cd /root/fan-imagehost
wget https://raw.githubusercontent.com/meimolihan/fan-imagehost/main/docker-compose.yml
docker compose up -d
```

启动后访问 `http://服务器IP:8083/`，按安装向导完成初始化；数据持久化在宿主机 `./fan-imagehost` 目录。

```shell
# 或直接使用 docker run
docker run -d \
  --name fan-imagehost \
  -p 8083:80 \
  --restart=always \
  -v /root/fan-imagehost:/var/lib/fan-imagehost \
  mobufan/fan-imagehost:latest
```

#### 一键脚本安装（systemd）

适用于直接部署在 Linux 服务器（非 Docker），自动安装 PHP 运行环境与扩展、注册 systemd 服务并安装内置命令 `fan-imagehost`。

```shell
# 默认端口 8083，数据目录 /var/lib/fan-imagehost/data
bash scripts/install.sh

# 自定义端口与数据目录，免交互
bash scripts/install.sh -p 8083 -d /var/lib/fan-imagehost/data -y
```

#### windows:

#### Linux:

- `git clone https://github.com/meimolihan/fan-imagehost.git` 至安装目录

- 赋予安装目录www:www和0755权限:
```shell
chmod -R 755 /安装目录
chown -R www:www /安装目录
```
- 有条件的建议开启OPcache
